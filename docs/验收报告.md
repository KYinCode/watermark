## 5. 已知边界与未覆盖项(如实报告)

### 5.1 组合搬运一条龙(#9)的内容相关性

- 全强度一条龙(镜像+裁切+轻调色+720p+贴片):动画/网格类内容(好段)**79.7%** 达标(≥60);
  UI 录屏类内容(高动态段)**2.7%** 未达。
- 根因(实验 s4/s9b):镜像×裁切 存在 WAM 模型级组合盲区(确定性错码),镜像重试可完全恢复
  (两段 91.4%/87.1%,见 R2 实验);但叠加 裁切×缩放×调色 后,48 组精确逆补偿网格均无法恢复(0%)。
- 可观赏性分析(样本见 output/samples/):含镜像的组合对 UI 录屏内容本身不可读(文字反写),
  现实威胁有限;但无镜像的现实强度组合(裁切+轻调色+720p+贴片)在 UI 内容上同样未达(2.7%),
  属当前模型档位(scaling_w=2.0,PSNR 39.6)下的真实边界。
- 若需覆盖该场景,可选 scaling_w=3.0 重嵌(预计 PSNR ~35,低于 36 线),未执行,待需求方决策。

### 5.2 单帧直解与工具链

- 亮度 -20%:好段单帧直解 75.2%,工具链(亮度补偿网格)**87.1%** ≥80 ✓;高动态段直解 99.7%
