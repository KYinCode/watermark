### 2.3 任务 2b:10-bit 编码 × 三强度矩阵(已完成,**不达标**)

数据(`experiments/out/t2b_matrix/summary.json` + `control.json`,两段各 660 帧:深蓝网格 5000 起 / 白底 UI 17800 起;x265 10bit crf14 preset medium;诊断帧 5100/17900):

**色偏(达标线:深蓝区 ΔB 相对红绿多降 ≤0.5;白区泛黄减半)**

| 配置 | 深蓝区 extraB(C 纯编码,vs_meanRG 口径) | 白区 ΔB(A 成品 vs 原始) |
|---|---|---|
| 基线:8bit h264 crf14 现役成品 | 1.05 / 0.81(两段) | -1.97 / -2.25 |
| 10bit sw=1.5 | 0.87 / 0.91 | -2.12 / -1.97 |
| 10bit sw=2.0 | 1.03 / 1.09 | -2.36 / -2.20 |
| 10bit sw=3.0 | 1.09 / 1.76 | -2.83 / -3.25 |
| **无水印对照** x265 10bit | 0.60 / 0.52 | **-1.73 / -1.93** |
| **无水印对照** x264 10bit | 0.81 / 0.39 | **-1.73 / -1.91** |
| **无水印对照** x264 8bit(现役配置) | 0.88 / 0.12 | **-0.99 / -0.96** |
| **无水印对照** x264 8bit crf10 | 0.60 / 0.09 | -0.97 / -0.96 |

**鲁棒性(10bit 小样)**:直解 exact 全部 100%;crf23 录屏重编码后 99.9%~100%(三档强度都达标;sw=1.5 鲁棒性补上了实测数据)。

**结论**:①位深不是色偏主因——无水印纯编码下 10-bit 对白区的偏移(-1.7~-1.9)反而比现役 8-bit 配置(-0.96)更大(疑与 x265 SAO/码控有关),4:2:0 色度处理才是主因;②**达标线两条均未达成,不建议按 2b 配方全片重嵌**;③现役 x264 8bit crf14 恰是各配置里对白区最友好的;④附带收获:sw=1.5 的鲁棒性实测通过,WebUI"隐形优先"预设可以放心标住。**等用户拍板:维持现状(推荐,成品 2a 后色彩标签已正确)或授权试其他方向(如 x265 关 SAO / 4:4:4 兼容性差的实验)。**

## 5. 踩坑记录(新会话逐条看完再动手)

1. 每条 Bash 先 `source wm_env.sh`;python 用 `$PY` 全路径。**shell 重定向 `> log` 的目标目录必须先存在**(两次事故)。
2. **GPU 严格串行**,一次只跑一个 GPU 进程;`common.load_wam` 已锁 45% 显存护栏。
3. 长任务日志直写文件(`> x.log 2>&1`);后台链用 `&&` 不用换行。
4. **shell 里写含反斜杠/转义的文件禁用 printf**(`\\` 会被吃掉),用 python 写——本次 JSON 请求文件两次踩坑。
5. **常驻服务里 spawn ffmpeg 必须 `-nostdin` + `stdin=DEVNULL`**:否则 ffmpeg 继承常开的 stdin 管道,交互监听线程阻塞导致"写完不退出、stdout 永不 EOF"(本次提取挂死 4 次的根因)。
6. **strategy_chain 已改惰性生成器**(`iter_trials`):命中路径从 ~0.5s/帧 降到 ~30-60ms/帧;语义与旧版一致,勿回退成预构建全列表。
7. `threading.Lock` 不可重入:store.py 的 edit/delete 持锁调 load() 会死锁,已换 RLock。
8. FastAPI 弹层按钮:openModal 的 footer 数组在调用时即消费,后 push 的按钮进不了 DOM(前端已修)。
9. 浏览器缓存顽固:静态资源已加 `Cache-Control: no-cache` 中间件 + index 资源带 `?v=启动时间戳`,改前端后重启后端即生效。
10. IAB/Playwright `fill()` 只派发 `input` 事件:表单联动要绑 `oninput`(时间输入框已改)。
11. 提取"未知 ID"阈值 conf≥3.0:soft_bits 返回的是 logits,噪声 conf≈0.5(重度增广可到 1.9),真解码 ≈9+,勿用 0.x 级阈值。
12. 杀进程先查清 PID;`webui/data/jobs.json` 是任务历史,手工删除会丢历史。
