## 5. 踩坑记录(新会话逐条看完再动手)

1. 每条 Bash 先 `source wm_env.sh`;python 用 `$PY` 全路径。**shell 重定向 `> log` 的目标目录必须先存在**(两次事故)。
2. **GPU 严格串行**,一次只跑一个 GPU 进程;`common.load_wam` 已锁 45% 显存护栏。
3. 长任务日志直写文件(`> x.log 2>&1`);后台链用 `&&` 不用换行。
4. **shell 里写含反斜杠/转义的文件禁用 printf**(`\\` 会被吃掉),用 python 写——本次 JSON 请求文件两次踩坑。
5. **常驻服务里 spawn ffmpeg 必须 `-nostdin` + `stdin=DEVNULL`**:否则 ffmpeg 继承常开的 stdin 管道,交互监听线程阻塞导致"写完不退出、stdout 永不 EOF"(本次提取挂死 4 次的根因)。
6. **strategy_chain 已改惰性生成器**(`iter_trials`):命中路径从 ~0.5s/帧 降到 ~30-60ms/帧;语义与旧版一致,勿回退成预构建全列表。
7. `threading.Lock` 不可重入:store.py 的 edit/delete 持锁调 load() 会死锁,已换 RLock。
8. FastAPI 弹层按钮:openModal 的 footer 数组在调用时即消费,后 push 的按钮进不了 DOM(前端已修)。
9. 浏览器缓存顽固:静态资源已加 `Cache-Control: no-cache` 中间件 + index 资源带 `?v=启动时间戳`,改前端后重启后端即生效。
10. IAB/Playwright `fill()` 只派发 `input` 事件:表单联动要绑 `oninput`(时间输入框已改)。
11. 提取"未知 ID"阈值 conf≥3.0:soft_bits 返回的是 logits,噪声 conf≈0.5(重度增广可到 1.9),真解码 ≈9+,勿用 0.x 级阈值。
12. 杀进程先查清 PID;`webui/data/jobs.json` 是任务历史,手工删除会丢历史。
13. **rawvideo(无标签)输入时,编码 `-colorspace/-color_primaries/-color_trc` 三件套只有 matrix 能写进 h264 VUI**,transfer/primaries 落 unknown(有标签输入则都能写)。必须在 `-vf` 链尾加 `setparams=color_primaries=bt709:color_trc=bt709:colorspace=bt709` 才齐(2026-09-06 冒烟测试发现并修复,两引擎均已加)。
14. **杀进程禁用窗口标题通配符**(`taskkill /FI "WINDOWTITLE eq xxx*" /T /F`):会命中一切同前缀顶层窗口(WebUI 页面的浏览器窗口、同名文件夹的资源管理器窗口、宿主控制台)并整树强杀——2026-09-12 实测连带杀掉宿主 shell 与用户桌面进程,造成黑屏。杀进程只用 netstat/tasklist 查到的**具体 PID**。
15. **bat 增删改行后必须整文件实跑一遍看输出**:cmd 解析器在 UTF-8 无 BOM + chcp 65001 的 bat 里会把(新增的)中文 rem/echo 行从多字节字符中间劈开("检测暴露"被当命令执行;位置与内容耦合,无法静态预判)。规避:新增注释用 ASCII 短行、中文提示行合并精简;验收标准 = 运行输出零 "不是内部或外部命令/语法不正确"。
16. **findstr 搜索串首尾别放反斜杠紧贴引号**:`/c:"\envs\wm2\"` 的 `\"` 被 CRT 参数解析当转义引号,吞掉后续参数、匹配永远失败(2026-09-12 启动自愈链的安全阀判定因此失效);写 `/c:"envs\wm2"` 这类首尾无反斜杠的字面串。
