# watermark-v2 提取工具使用说明

## 环境准备(一次性)

1. conda 环境(名字 `wm2`,Python 3.10):

   ```bash
   conda create -n wm2 python=3.10 -y
   conda activate wm2
   pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu124
   pip install -r third_party/watermark-anything/requirements.txt
   python -c "import torch; print(torch.cuda.is_available())"   # 必须 True
   ```

   完整依赖与版本见 `environment.yml`。
2. 模型权重:`third_party/watermark-anything/checkpoints/wam_mit.pth`(MIT 许可,377MB,
   来源 https://dl.fbaipublicfiles.com/watermark_anything/wam_mit.pth )。
3. 码本:`tools/codebook.json`(水印 ID `96e6955d` ↔ 完整版权文本的映射,随成品交付)。
4. 需 NVIDIA GPU(实测 RTX 4060 Laptop 8GB 即可,占用约 2.5GB)。

## 提取命令

```bash
conda activate wm2
cd F:\Project\watermark

# 视频按时间点提取(秒),自动 ±0.5s 邻域重试 + 多帧投票
python tools/extract_wm.py video "DeepSeek+DSH_已加水印_v2.mp4" --t 100

# 视频按帧号提取
python tools/extract_wm.py video "DeepSeek+DSH_已加水印_v2.mp4" --frame 6000

# 邻域窗口可调(默认 ±0.5s)
python tools/extract_wm.py video "DeepSeek+DSH_已加水印_v2.mp4" --t 100 --window 1.0

# 单帧图片(成品图/截图/裁剪图均可)
python tools/extract_wm.py image "某张截图.png"
```

输出 `版权文本` 即解码结果;退出码 0=命中,3=未命中,2=无有效区域。

## 内置两步式策略链

单帧解码依次尝试,任一策略解出的 ID 与码本匹配即返回:

1. 全帧直解(1:1、转码、常规画质攻击场景)
2. 全帧镜像解(镜像搬运 / 组合搬运场景)
3. 亮度补偿网格 ±13/26/39/51(亮度攻击)
4. 色相反补偿网格 ±12/24/36/48/60/72(滤镜调色攻击)
5. 定位 mask 主连通域裁剪解(包边、画中画、贴片后仅剩部分水印区域)
6. 3×3 多窗搜索(每窗 50% 面积;包边缩放 70% 等背景污染场景)
7. 角度搜索(±10° 步长 1°,±45°~75° 步长 2°;旋转取证)

视频模式额外利用时域冗余:邻域内逐帧执行策略链后统计命中帧数,
单帧失败不影响整体结论。

## 水印编码方案

- 模型:WAM(watermark-anything)MIT 权重 `wam_mit`,32-bit 多比特水印,逐帧独立嵌入。
- 载荷:32-bit 固定 ID = 版权文本 UTF-8 的 SHA-256 前 4 字节(大端),即 `96e6955d`。
- 还原:提取端比对 `codebook.json`,命中即输出完整文本
  `©Yin(Yin_Code/KYin_Code/KYin)版权所有|禁止搬运 Bili:3706940936948128 Douyin:Yin_Code`。
- 误报率:未知画面恰好解出该 ID 的概率 ≈ 2^-32,且要求 mask 检出区域 ≥8 像素。

## 局限(如实说明)

- 时间轴整段替换的内容本身无水印,无法防御(需求书边界)。
- 手机翻拍链路(透视+摩尔纹+白平衡)未实测,不设达标承诺。
- 组合搬运一条龙(镜像+裁切+调色+降清+贴片)在动画/网格类内容达标(79.7-91.4%),
  在 UI 录屏类内容未达(2.7%,模型级组合盲区,详见验收报告 5.1)。
